# VoxKey — dictation fix (11 Aug 2026)

## What was actually wrong

1. **Black Command Prompt window on every hotkey press.**
   `VoxKey.spec` built the Whisper worker with `console=True`, and the worker was
   launched without `CREATE_NO_WINDOW`. Every dictation spawned a console.

2. **Nothing was ever dictated.**
   The worker was spawned *fresh for every dictation*, loading the whole Whisper
   model from scratch each time. Any failure inside it was swallowed
   (`capture_output=True`, output never read) and surfaced as the useless popup
   "Speech engine could not run…". Nothing was ever logged, so there was no way
   to see why.

3. **Even when text came back, the paste often did nothing.**
   After holding `Ctrl+Shift` as the push-to-talk hotkey, Windows still believes
   Ctrl/Shift are physically down. The old code then fired `Ctrl+V` via pynput —
   which the OS saw as `Ctrl+Shift+V`, so most apps inserted nothing.

4. **Voice Setup error.**
   `tray.py` line 149: `from .recorder import has_speech` — there is no
   `whispr.ui.recorder`. Calibration threw `ModuleNotFoundError` on the first
   click, shown as "Mic error: No module named 'whispr.ui.recorder'".

5. **Silent dead-ends.** If VAD decided there was no speech, or the mic failed to
   open, the app returned to idle with no message at all.

## What changed

- `whispr/core/transcribe_worker.py` — rewritten as a **persistent worker
  process** with a JSON-line protocol over raw file descriptors (safe in a
  windowed PyInstaller exe). Model loads **once**, then each dictation is a
  sub-second round trip.
- `whispr/core/transcriber.py` — rewritten to manage that process:
  `CREATE_NO_WINDOW`, stderr drained into `voxkey_runtime.log`, automatic
  restart-and-retry if the worker dies, real error messages, `load()` for
  warm-up, `shutdown()` on quit. PyInstaller `_PYI*` env vars are stripped
  before spawning the child exe.
- `whispr/core/output.py` — rewritten paste path: native Win32 clipboard (with
  pyperclip fallback), **forces every modifier key up** before pasting, sends
  `Ctrl+V` via `keybd_event`, restores the previous clipboard afterwards.
- `whispr/core/controller.py` — added an `on_status` channel; VAD can no longer
  swallow real speech (a mis-calibrated threshold now falls through to Whisper),
  and trimming to empty falls back to the untrimmed audio.
- `whispr/ui/tray.py` — fixed the Voice Setup import bug, warms the model in the
  background at startup, shows status/error balloons, logs every hotkey edge,
  adds an "Open log folder" tray menu item, shuts the worker down on quit.
- `VoxKey.spec` — worker exe is now `console=False` with the app icon.

## Build

Unchanged: push to GitHub, Actions runs `PyInstaller VoxKey.spec` then Inno
Setup, artefacts `VoxKey-Setup` and `VoxKey-app`.

## If it still misbehaves

Tray → **Open log folder** → `voxkey_runtime.log`. It now records: hotkey down,
hotkey up, worker start, model load, every worker stderr line, and the exact
failure. Send that instead of guessing.
